# Celestia releases

This repository only holds the installers of **Celestia**, a desktop app for collecting visual references on Windows,
and the small files its automatic updates read. There is no source code here.

Celestia is in a private alpha: the app needs a personal access key to open. If you would like to try it, keep an eye
on the website (coming soon).

---

Este repositório só guarda os instaladores do **Celestia**, um app de desktop para juntar referências visuais no
Windows, e os arquivos pequenos que a atualização automática lê. Não há código aqui.

O Celestia está numa alpha fechada: o app precisa de uma chave de acesso pessoal para abrir. Se quiser testar, fique de
olho no site (em breve).
